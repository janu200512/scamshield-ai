# ScamShield AI completion checklist

## Product
- [ ] Run the Devpost Learn Skill Pack workflow and review its generated artifacts.
- [ ] Confirm the analyzer works with no API key.
- [ ] Test empty and >5,000-character inputs.
- [ ] Test scam and legitimate examples; record false positives/negatives.
- [ ] Check mobile layout and keyboard use.
- [ ] Confirm the UI never describes heuristic score as probability.

## Repository
- [ ] Replace draft status in planning docs after Skill Pack review.
- [ ] Add an open-source license approved by the project owner.
- [ ] Add screenshots and final deployed URL to README.
- [ ] Ensure `.env.local` is not committed.
- [ ] Verify public repository and build logs.

## Submission
- [ ] Deploy and test the live app on a separate device.
- [ ] Record a demo video under 3 minutes.
- [ ] Complete Devpost project description, links, and Learn Skill Pack usage question truthfully.
- [ ] Submit before the official deadline.
